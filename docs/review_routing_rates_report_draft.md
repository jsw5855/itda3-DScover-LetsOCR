## X. OCR 결과의 운영 분기와 위험

### X.1 설계: 신뢰도 기반 검토 분기

OCR이 읽은 날짜를 모두 자동 승인하면 오류가 그대로 매장 운영에 반영된다. 반대로 모두 사람이 확인하면 자동화 효과가 사라진다. 그래서 파이프라인이 이미 계산하는 정보만으로 결과를 네 가지 처리 경로로 나누었다. 새로운 모델이나 추가 연산은 필요하지 않다.

| 경로 | 조건 | 직원 작업 |
|---|---|---|
| 수동 입력 | 연·월·일 중 하나라도 읽지 못함 | 날짜 입력 |
| 후보 선택 | 서로 다른 날짜 후보가 2개 이상 (예: 제조일과 소비기한) | 후보 선택 |
| 재확인 | 선택된 날짜의 문자 인식 신뢰도 < 0.90 | 이미지 확인 |
| 확인 후 승인 | 위에 해당하지 않음 | 승인 |

### X.2 평가 방법

- 데이터: 식품 포장 사진 701장. 저장된 OCR 결과를 현재 제출 파이프라인의 판단 로직으로 다시 계산했다. OCR을 다시 실행하지 않았다.
- 두 번의 독립적인 OCR 실행 기록으로 같은 계산을 하면 701장 모두 경로와 예측이 일치했다.
- 비율의 95% 신뢰구간은 Wilson 방법으로 구했다.
- 날짜 오류는 방향으로 나눴다.
  - 실제보다 늦은 날짜로 읽으면 기한이 지난 상품이 통과할 수 있다(안전 위험).
  - 실제보다 이른 날짜로 읽으면 판매 가능한 상품을 일찍 폐기할 수 있다(손실).

### X.3 결과

**표 X-1. 처리 경로 분포 (701장)**

| 경로 | 비율 | 95% 신뢰구간 |
|---|---:|---:|
| 수동 입력 | 16.7% | 14.1–19.6% |
| 후보 선택 | 12.6% | 10.3–15.2% |
| 재확인 | 7.3% | 5.6–9.4% |
| **직원 검토 합계** | **36.5%** | **33.0–40.1%** |
| 확인 후 승인 | 63.5% | 59.9–67.0% |

**표 X-1b. 직원 검토 36.5%의 실제 작업 구성 (상품 100개당)**

| 실제 직원 작업 | 상품 100개당 | 설명 |
|---|---:|---|
| **처음부터 날짜 직접 입력** | **9.1개** | OCR이 날짜를 아예 못 읽음 (64장) |
| 날짜 일부만 있음 → 보충 입력 | 7.6개 | 53장 중 **45장은 인쇄된 그대로 정확히 읽음**. 제품에 원래 일(day)이 없거나(연·월만 인쇄, 39장) 연도가 없음(월·일만 인쇄, 14장) |
| 후보 2개 중 하나 탭 | 12.6개 | 88장 중 **82장(93%)은 정답이 후보 안에 있음** |
| 사진 보고 맞는지 확인 | 7.3개 | 51장 중 **41장(80%)은 이미 정답** |
| **합계 (직원 검토)** | **36.5개** | |

*정답 포함률과 정답 비율은 대부분 미검수 라벨 기준의 참고 수치다.*

**표 X-2. 확인 후 승인 경로의 오류 (701장 대비)**

| 오류 | 비율 | 95% 신뢰구간 | 비고 |
|---|---:|---:|---|
| 전체 | 3.4% | 2.3–5.0% | 승인 경로 안에서는 5.4% |
| 늦은 날짜 (안전 위험) | 1.1% | 0.6–2.2% | 8건 중 4건은 차이 7일 이내 |
| 이른 날짜 (폐기 손실) | 2.3% | — | 16건 중 8건은 차이가 약 1·2·3·5년 |

**표 X-3. 재확인 기준에 따른 부담과 위험 (참고)**

| 재확인 기준 | 직원 검토 | 승인 경로 오류 | 늦은 날짜 |
|---|---:|---:|---:|
| 0.85 | 31.4% | 4.0% | 9건 |
| **0.90 (적용)** | **36.5%** | **3.4%** | **8건** |
| 0.95 | 54.9% | 1.7% | 2건 |

### X.4 해석

- 결과의 약 3분의 2는 직원이 승인만 하면 된다. 나머지 3분의 1은 오류가 날 만한 경우를 골라 직원에게 보여 준다.
- 검토 대상 중 날짜를 처음부터 입력해야 하는 경우는 전체의 9.1%에 그친다. 나머지는 후보 선택(정답 포함 93%), 이미지 확인(80%는 이미 정답), 인쇄되지 않은 일부 날짜 보충 같은 가벼운 작업이다. 전량 수기 확인과 비교하면 직원이 직접 입력하는 양이 약 10분의 1로 준다.
- 연·월만 인쇄되었거나 연도가 없는 제품(7.6%)은 대부분 OCR이 인쇄된 그대로 읽은 경우다. 월말 보정이나 연도 추정 규칙을 더하면 검토 비율을 더 낮출 수 있다(향후 과제).
- 안전 위험(늦은 날짜)은 전체의 1.1%다. 이 중 절반은 차이가 7일 이내로, 숫자 한 자리 오인식에서 생긴다.
- 이른 날짜 오류의 절반은 차이가 거의 정확히 1년 단위다. 제조일을 소비기한으로 고르거나 두 자리 연도의 읽는 순서를 잘못 해석한 경우로 보이며, 다음 개선 대상으로 삼는다.
- 재확인 기준은 매장의 운영 방침에 맞춰 조정할 수 있다. 0.95로 올리면 안전 위험이 8건에서 2건으로 줄고, 검토량은 약 1.5배가 된다.
- 재시도 정책(고해상도 재인식) 도입으로 정확도는 올랐지만, 안전 위험 건수는 늘지 않았다(8건 → 8건).

### X.5 ROI 산식

```text
직원 시간/개 = 0.167·T_입력 + 0.126·T_선택 + 0.073·T_확인 + 0.635·T_승인
절감률       = 1 − 직원 시간 / T_입력          (전량 수기 입력 대비)
```

T 값은 매장 실측 또는 문헌값을 쓴다. 예를 들어 T_입력 15초, T_선택 5초, T_확인 5초, T_승인 2초로 가정하면 개당 약 4.8초, 절감률은 약 68%다.

### X.6 한계

- 평가 사진에는 개발 과정에서 사용한 사진이 포함되어 있어 독립 검증 수치가 아니다.
- 오류율은 대부분 미검수 정답 라벨 기준이다. 검수 확정 69장에서는 승인 경로 오류가 4건이다.
- 식품 포장 기준이며, 화장품이나 매장 현장 사진에서는 분포가 달라질 수 있다.
- 신뢰구간은 표본 크기에서 오는 오차만 반영한다.
