## 판정 기준

- **OCR 문제**: 이미지에 인쇄된 글자를 **그대로** Parser(예선 최종본)에 넣으면 정답이 나오는데, 예선 v6 실제 실행은 틀린 경우
- **Parser 문제**: 인쇄 글자를 그대로 넣어도 Parser가 틀리는 경우 → Parser 담당이 처리

주의: 예선 실행 결과에는 OCR이 읽은 원문이 저장되지 않아서, 아래는 **간접 근거**입니다.
701장 재실행(4단계 OCR 원문 저장) 후 원문으로 다시 확인할 예정입니다.
"v5 시절 원문"은 예선 중간(`outputs/cascade_failures_debug.csv`, 인식 모델은 현재와 동일, 검출 모델은 v5)의 기록입니다.
