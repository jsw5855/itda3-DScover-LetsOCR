- **이미 측정한 사실**(701장)
  - 두 자리 연도를 전부 일.월.년으로 바꾸면 **+7장 / −42장**이다. 틀리는 쪽은 대부분 한국 제품의 `26.04.24`(연.월.일)다.

  3. 안내 문구 패턴에 `일-월-년`(하이픈)을 추가한다. 지금은 `[,./·]`만 인식해서 `소비기한(일-월-년 순 까지)`를 놓친다. 위험은 낮다. 다만 이 문구가 있는 000844는 라벨이 의심되니 E를 참고한다.

## 4. 우선순위 제안

1. **라벨 확인** (E 2장 + D 중 늦은 날짜 5장): 규칙을 만들기 전에 오류가 진짜인지 확인한다.
2. **cascade의 highres 후보 감소 처리** (B, 선우와 협의): Policy B가 만든 조용한 오류 3장을 직접 겨냥한다.
3. **안내 문구 `일-월-년` 추가** (A-3): 위험이 낮다.
4. **제조일 키워드 재측정** (B): `P.D` 등을 Policy B 기준으로 다시 잰다.
5. **영문 키워드 + 두 자리 연도 → 일.월.년** (A-1): 효과는 크지만 위험도 크다. −목록을 꼼꼼히 본다.
6. 붙거나 끊긴 숫자 (C)
